# 论文图 2 曲线数字化参考

来源：[De Raedt & Michielsen, Computers in Physics 8, 600–607, Fig. 2](https://doi.org/10.1063/1.168483)。虚线是论文数值结果，实线是孔径近似。`figure2.png` 是 PDF 第 7 页在 300 dpi 下渲染并裁出的 1117×798 像素图，文件哈希、裁切坐标及轴刻度记录在 `digitization.json`。

## 提取方法

`digitize.py` 只读取图像，不读取 FR 解，也不使用衍射公式。先按上下横轴的九组刻度及纵轴标定坐标，补偿扫描倾斜；去除中央坐标轴、横向短刻度和底部边框。随后按九个亮峰划分图像窗口，在每个峰的左右支路逐行追踪墨迹。窗口只限定图像区域，不指定峰高。可分离的短虚线优先于细实线；短虚线之间使用保形插值，无法分离的墨迹保留重叠标记。

中央归一化点采用论文 P(0)=1 的定义，明确标为坐标轴遮挡，不参加误差计算。没有估计峰位、峰高、暗谷强度的手工数值锚点。路径保留左右差异，没有强制对称化。

图像追踪生成 4,935 个逐行轨迹位置，按 0.1° 分箱得到 **904 个路径点**。其中 35 个分箱包含可分离虚线，740 个涉及虚实线重叠，128 个位于可见短虚线之间，1 个为被坐标轴遮挡的归一化点。重叠墨迹不等于已恢复作者的独立数值数据；数量增加也不等于数据精度提高。

## 文件与状态码

- `figure2.csv`：904 个路径点。列为 `angle_degrees, normalized_intensity, pixel_x, pixel_y, status, pixel_halfwidth, lobe, branch`。
- `figure2_trace_rows.csv`：分箱前的逐行路径，用于复核。
- `trace_overlay.png`：所有路径点回投到原图，按状态着色。
- `digitization.json`：图像来源、校准刻度、方法版本和各类点数。

| status | 含义 | 是否用于描述性 RMSE |
|---|---|---|
| 1 | 可分离的虚线墨迹 | 是 |
| 2 | 虚实线重叠或不可唯一分离的可见墨迹 | 是，但必须连同读图敏感性范围解释 |
| 3 | 中央坐标轴遮挡，使用归一化定义 | 否 |
| 4 | 虚线间隙的插值路径 | 否 |
| 5 | 尾部与横轴合并，仅在完整显示曲线中出现 | 否 |

`reconstruct.py` 将路径以保形插值连接为 -80° 至 80° 的完整显示曲线。横轴合并的尾部使用基线显示，并以状态 5 标识，不声称恢复了不可见的小幅振荡。`paper_reconstructed.csv` 导出完整曲线和状态码，灰色点线表示间隙、遮挡和基线限制部分。

RMSE 只对状态 1、2 的 775 个分箱取描述性差异。另让每个读数在可见水平线宽、0.15° 标定余量和 3 像素纵向余量内变化，报告读图敏感性范围；这是敏感性分析，不是统计置信区间。它不足以支持精细的数值方法排名。

## 复现与检查

```bash
python -m case.quantum_double_slit.digitize
python -m case.quantum_double_slit.compare
```
