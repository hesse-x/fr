# 圆柱绕流原生算子性能

参照 channel-dns 的局部通量计算、工作区复用及融合 RK 思路，实现 PyTorch CPU 自定义 C++ 算子，使用 ATen 分配 Tensor、`at::parallel_for` 按单元并行。没有使用 ctypes 调用外部库。对照基线为未改动的 NACA0012-NS 空间物理和 SSPRK(4,3)，使用同一圆柱网格、同一扰动初场和物理参数。

早期性能基准使用当时的默认圆柱网格：4,218 个三次曲边三角形，p=2，25,308 个状态点，体积/面过积分参数 6；Re=100、Ma=0.1、CFL=0.2。当前默认已改为结构四边形；复测早期表格需显式传入 `--mesh case/cylinder_flow/results/mesh/coarse.msh`。CPU 为 Intel i7-14700，PyTorch 2.14.1+cu130，计算使用 CPU FP64。编译 `-O3 -std=c++20 -march=native -fopenmp -ffp-contract=fast -fno-math-errno`，未启用 fast-math。

## 保留的实现

- 在每个单元内融合体通量、面通量与导数/提升，避免全域通量张量。
- 黏性面只计算法向应力及热通量，不构造完整方向张量。
- 三个依赖阶段间设置并行同步：初始迹、BR1 梯度及梯度迹、残差。
- 完整四阶段 RK 在一次 `torch.ops.cylinder_flow.step` 中完成，复用步内梯度/面迹工作区和阶段 RHS 缓冲。
- CFL、节点/面/体积点正性检查、残差归约均使用 C++ 算子。每个完整步后仍检查状态和残差。
- 保留独立 Torch 参照和与边界动量通量一致的载荷后处理。

## 测量

预热 3 步，每组计时 10 步，3 组取中位数；交替执行基线/原生顺序，并逐组检查终态一致性。完整计时含四次新 RHS、CFL、有效性检查、残差，不含 JIT 编译和磁盘输出。两条路径均从相同初场启动，输出负载相同。不同线程行来自不同批次，不能用于严谨的跨线程伸缩归因。

| 线程数 | Torch 基线秒/步 | 原生秒/步 | 同批加速比 |
|---|---:|---:|---:|
| 1 | 0.25320 | 0.05505 | 4.60× |
| 4 | 0.11837 | 0.01420 | 8.34× |
| 4（最终复测） | 0.12758 | 0.01430 | 8.92× |

首轮 4 线程原生三组为 `0.014200 / 0.014328 / 0.013901` 秒/步；计时段次要缺页均为 0，CPU 使用量约 4 核。基线同批三组为 `0.118366 / 0.119522 / 0.114236` 秒/步。最终复测原生三组为 `0.014299 / 0.014804 / 0.014034`，基线为 `0.143681 / 0.127419 / 0.127578`，完整记录保存于 `results/performance/native.json`（生成输出不纳入 Git）。最终默认 4 线程；硬件与系统负载变化会影响结果，可运行 benchmark.py 重新测量。

## 总推进成本

默认设置的显式黏性步长非常保守，初始最小物理步长约 `1.05195e-6`，每步对流时间约 `1.05195e-7`。20 步短测仅推进至 `t U_inf/D=2.1039e-6`，不是涡街结果。即使单步加速，百万步也可能远未达到目标对流时间 100；脚本不会自动放宽稳定性估计。

## 已完成的 GIF 演示计算

采用 README 的演示参数：1,004 单元、p=1、过积分参数 4、Re=100、Ma=0.2、CFL=0.5、扩散步长系数 64，全局物理时间推进 284,158 步，达到对流时间 `100.0002779`，没有非物理候选步被拒绝。4 线程绑定 CPU `0,2,4,6`，推进含日志/检查点约 404.5 秒；GIF 渲染另计。这组演示网格/阶数不同于上方性能基准，不能直接比较秒/步。

输出位于 `results/karman_p1_re100/`：`vorticity.gif` 为 150 帧、1100×440、约 6.6 MiB，采样对流时间 `40.0000845–100.0002779`；另有末时刻 PNG、真实采样时间、载荷历史和检查点。GIF 各相位显示尾迹交替摆动和脱涡。对流时间 50 之后 CL 范围约 `[-0.3129,0.2633]`，相邻向上零交叉平均间隔约 `6.3893`，本算例测得 `St≈0.1565`。记录见 `verification.json`。这些是粗网格演示值，未进行网格无关性或定量基准验证；远尾迹网格较粗，涡结构传播后会明显耗散。

从同一个对流时间 `35.9404371` 的检查点，分别以 CFL=0.5 和 0.25 继续约两个对流时间。两者终态相对欧氏范数差 `2.75e-6`、最大状态差 `1.80e-5`、CL 差约 `9.9e-6`；终止时间差小于一个粗时间步。记录见 `timestep_check.json`。这是短程时间步敏感性检查，不是完整时间收敛证明，也不授权将步长系数 64 泛用于其他网格。

## 多块结构网格

按用户要求改为 O 型贴体四边形和十字加密区。4 个贴体块、8 个矩形外围块，默认 7,760 单元，p=1 时 31,040 解点；水平/竖直密网格从中心方框 `[-2,2]²` 延伸至整个计算域边界。体积、共享曲边和 Jacobian 检查通过，面积误差约 `9.26e-9`，最小 Jacobian `0.0027435>0`。网格 PNG/SVG 和生成参数位于 `results/mesh/structured.*`。

原生算子的每单元边数由固定 3 扩展为 3/4，几何导数、提升、BR1 迹及 CFL 继续使用框架预计算矩阵。四边形 p=1/2 的非均匀 RHS、两种时间模式和 RK 终态与独立 Torch 参照一致。8 项圆柱测试以及原 NACA-NS 的 4 项测试通过。

将粗网格对流时间 `100.0002779` 的守恒变量通过物理点定位和新单元积分 L2 投影到结构网格。整体质量积分差约 `1.71e-4`（相对 `2.85e-7`），能量积分差约 `4.49e-4`（相对 `4.15e-7`）；未施加人为平滑。报告位于 `results/structured_transfer/solution.json`。此投影采用有限积分点，不是几何交叠意义上的严格守恒转移。

结构网格先以 CFL=0.5 推进到对流时间 100.5，再采用 CFL=1。将同一 100.5 检查点分别用 CFL=1 和 0.5 推进约两个对流时间，并用最后一个局部缩短的全局 RK 步对齐到同一物理时刻，状态相对欧氏范数差 `7.34e-8`、最大分量差 `2.02e-6`、CL 差 `1.25e-6`。记录位于 `results/karman_structured_re100/timestep_check.json`。这是短程时间步敏感性检查，不是完整时间收敛证明。

结构网格最终推进至对流时间 `140.0003213`，新网格累计 52,784 步，候选状态没有因非物理性被拒绝。主续算段为对流时间约 102.5–140，8 个 P 核推进及检查点约 470 秒，GIF 渲染另计；该期间还在 E 核运行了时间步对照，不作严格性能基准。

最新 GIF 位于 `results/karman_structured_re100/vorticity.gif`，120 帧、1100×440，覆盖对流时间 120–140。色标、视口、单元内采样方式与之前一致，没有跨单元滤波。细结构网格使交替涡能在原来过早变粗的远尾迹继续传播；末时刻图和动画已目视检查。对流时间 120 之后 CL 范围约 `[-0.3090,0.3089]`，平均向上零交叉间隔约 `6.0933`，本次观测 `St≈0.1641`。与旧版 `St≈0.1565` 的变化也说明原结果存在空间分辨率影响；仍需更多网格和更长统计窗口验证，不能据两组不同拓扑网格宣布网格收敛。机器可读记录见 `verification.json`。
