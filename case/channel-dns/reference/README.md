# Reference data

`chan180.means` is the authors' original mean-profile table for Moser, Kim &
Mansour (1999), "Direct numerical simulation of turbulent channel flow up to
Re_tau=590", Physics of Fluids 11, 943–945, DOI: 10.1063/1.869966.

Source: https://turbulence.oden.utexas.edu/data/MKM/chan180/profiles/chan180.means

Database: https://turbulence.oden.utexas.edu/MKM_1999.html

Downloaded 2026-10-26; original header retained. Actual reference Re_tau=178.12.
Columns 2 and 3 are y+ and U+; no rescaling is applied. This is a qualitative
comparison when the computed Re_tau differs, not a matched-Re validation.
